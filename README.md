# Talogy Quarterly Update Site

You asked for a **non-technical way** to view a published site.

## Fastest option (no coding): Netlify Drop

1. Open this page: https://app.netlify.com/drop
2. Download this folder as a `.zip` (or zip it if needed) containing:
   - `index.html`
   - `styles.css`
3. Drag and drop the `.zip` into Netlify Drop.
4. Netlify instantly gives you a public URL like:
   - `https://something.netlify.app`
5. Share that URL with your leadership team.
